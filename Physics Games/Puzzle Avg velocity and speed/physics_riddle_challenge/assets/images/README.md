# Image assets

Every file listed here is **optional**. The game ships complete: each slot has
built-in CSS/SVG/canvas art that is used whenever the file is absent. Drop a
PNG in at the exact path below and it is picked up on the next page load with
no code change. Delete it again and the vector art returns.

All paths are relative to `assets/images/`.

Transparent PNG (32-bit RGBA) everywhere except the two backdrop skylines,
which may be opaque. Keep files under ~600 KB each so the WebView boots fast.

---

## background/ — parallax layers behind everything

| File | Size (px) | Orientation | Notes |
|---|---|---|---|
| `skyline_far.png` | 2560 × 1440 | landscape | Slow far layer. Anchored to **center bottom**, `cover`. Keep the busy detail in the lower third; the top is covered by UI. Rendered at 55 % opacity. |
| `skyline_near.png` | 2560 × 1440 | landscape | Faster near layer, drawn over `skyline_far`. Should be mostly transparent — silhouettes only. Rendered at 75 % opacity. |
| `grid_floor.png` | 2048 × 1024 | landscape | Optional replacement texture for the receding telemetry floor. |
| `vignette.png` | 2048 × 2048 | square | Overrides the built-in corner darkening. Mostly transparent in the middle. |

The animated canvas (light trails, drifting vectors, dust) draws **on top of**
`skyline_far`/`skyline_near` and stays active either way.

## ui/emoji/ — **required, already present**

These 31 PNGs replace every emoji the interface would otherwise need. They are
generated by `tools/gen_icons.mjs` (pure Node, no dependencies, fully offline):

```bash
node tools/gen_icons.mjs
```

All are 128 × 128 transparent PNGs. Replacing one by hand is fine — keep the
filename and the square 128 × 128 canvas.

| Group | Files |
|---|---|
| Navigation | `play`, `next`, `back`, `home`, `close`, `replay` |
| Answer feedback | `check`, `cross` |
| Audio toggles | `music-on`, `music-off`, `sfx-on`, `sfx-off` |
| Panels | `settings`, `briefing`, `datapad`, `lock` |
| Progress & reward | `star-on`, `star-off`, `trophy`, `medal`, `bolt`, `spark`, `beacon` |
| Physics theme | `speedometer`, `stopwatch`, `vector`, `scalar`, `track`, `flag`, `target`, `runner` |

Icons whose state is swapped at runtime (`music-on`/`music-off`,
`sfx-on`/`sfx-off`, `star-on`/`star-off`, `check`/`cross`) are changed by
setting the `<img>` `src`, never by writing text into an element.
