    How to Play

    Objective

    A specimen card is mounted on the stand. Decide whether its leaf is simple or compound and file it in the matching tray. Every level is a run of specimens — the more you file correctly, the more stars you earn.

    Controls

    • Drag the card onto a tray and release — works with finger, stylus or mouse.
    • Tap a tray to file the current card without dragging.
    • Keyboard: ← or S files as simple, → or C files as compound, Esc goes back.

    Scoring

    • One point per correctly filed specimen.
    • Consecutive correct files build a streak; a mistake resets it.
    • Stars per level: 3 at 100%, 2 from 80%, 1 from 60%.
    • Earning at least one star unlocks the next drawer of the cabinet.

    Curious about the botany itself? A full Learn More reference waits on the results screen.
