# characters/ — optional guide character (empty by default)

Leave this folder empty and no character is shown; nothing else changes.

| filename | shown on | suggested size | orientation |
|---|---|---|---|
| `mentor.png` | menu (bottom right) and result scroll (bottom left) | 520 x 780 | portrait |

PNG with transparency, full-body or bust, facing slightly left. Automatically
hidden on screens narrower than 560 px, and given a gentle bob animation unless
Reduced Motion is switched on in Settings. Full details in `../README.md`.
