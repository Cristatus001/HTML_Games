# Image assets

Everything in this tree is **optional** except `ui/emoji/`.

The game ships with complete procedural vector art. Drop a PNG in at the exact
path below and the game uses it automatically on next load; delete it and the
vector art comes back. A missing or corrupt file is never an error - the loader
checks `naturalWidth` and silently falls back.

Because the files are probed on every launch, you will see one `404` per absent
file in the browser console. That is expected and harmless.

- **Format:** PNG with transparency (RGBA), sRGB.
- **Orientation:** all art is drawn upright, facing the viewer; the game rotates
  pieces itself. Do not bake in rotation.
- **Sizing:** every image is scaled to fit its box while preserving aspect
  ratio, and is drawn centred on its anchor point. The sizes below are the
  recommended pixel dimensions for a 2x display - larger is fine, smaller will
  look soft.
- **Padding:** leave the subject tight to the canvas edges. The game adds its
  own glow, so do not bake a large transparent margin into the file.

## `ui/emoji/` - required, already generated

These 41 files replace every icon that would otherwise be an emoji character.
They are generated by the project's icon script and are referenced directly as
`<img>` tags, so they must exist. All are **128 x 128**, square, RGBA.

They come in two treatments:

- **Coloured** (`play.png`) - lit from within, for icons sitting on a dark
  panel: the HUD tool buttons, the objective strip, help lists, settings rows,
  stage medallions, the boot and title marks, and the result crest.
- **Mono** (`play_btn.png`) - near-white with a soft contact shadow, for icons
  sitting *on a coloured button face*. A hued icon fights its fill: an amber
  icon on the amber HOW TO PLAY button disappears, and a lime one clashed with
  the violet primary. One mono file reads correctly on violet, jade, rose,
  amber and steel alike.

Mono variants exist for the ten icons that appear inside a `.btn`: `play`,
`arrow_right`, `restart`, `microscope`, `hint`, `learn`, `settings`, `home`,
`animal_cell`, `plant_cell`. If you replace one of these by hand, supply the
`_btn` version too, or the button will show the coloured art.
